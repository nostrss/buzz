# 05: 데스크톱 커뮤니티 생성 화면

**What to build:** "커뮤니티 만들기" 카드를 누르면 이름 하나를 넣는 화면이 열리고, 입력하는 동안 `<이름>.app.pegboard.me` 미리보기와 가용성이 보인다. 만들면 upstream 흐름(접속 → 프로필 → 스타터 채널 → 환영 채널과 에이전트 킥오프)이 그대로 이어진다.

**Blocked by:** 03 (데스크톱 이메일 로그인 온보딩), 04 (커뮤니티 생성 API)

**Status:** ready-for-agent

- [ ] BuilderLab 클라이언트(Tauri 커맨드와 프런트 API)를 계정 서비스용으로 교체한다: 브라우저 로그인·신원 바인딩 커맨드는 제거하고, 이름 확인과 생성 커맨드만 남긴다. 보관·이전 커맨드는 미노출로 둔다.
- [ ] 생성 화면은 입력 하나. 타이핑 중 정규화 결과와 주소 미리보기, 디바운스된 가용성 표시("사용 가능 / 이미 사용 중 / 사용할 수 없는 이름: 사유").
- [ ] 생성 성공 시 응답의 릴레이 URL로 upstream의 커뮤니티 온보딩 트랜잭션을 시작해 로컬 목록 추가 → 접속 → 프로필 → 스타터 채널 → 환영 채널로 이어진다.
- [ ] 이미 하나를 만든 계정은 카드가 비활성이고 "계정당 하나" 안내가 보인다. 초대로 여러 커뮤니티에 들어가는 것은 제한이 없다.
- [ ] 설정의 hosted communities 카드와 "커뮤니티 추가" 다이얼로그도 같은 생성 화면을 쓴다.
- [ ] Playwright smoke: 두 카드 → 이름 입력 → 미리보기와 가용성 → 생성 → 환영 채널 진입, 두 번째 생성 시 안내.
