# 06: 키 관련 화면 미노출과 커뮤니티 나가기

**What to build:** 플래그가 켜져 있으면 사용자는 앱 어디에서도 nsec, npub, 키 내보내기·가져오기, 폰 페어링, "기존 키 사용"을 보지 않는다. 멤버는 커뮤니티에서 나갈 수 있다.

**Blocked by:** 03 (데스크톱 이메일 로그인 온보딩)

**Status:** ready-for-agent

- [ ] 플래그가 켜져 있으면 설정의 키 내보내기·백업·가져오기 카드와 모바일 페어링 카드가 렌더링되지 않는다.
- [ ] 릴레이 프로필 온보딩 단계의 "기존 키 사용"과 "키 다시 가져오기" 경로가 렌더링되지 않는다.
- [ ] 플래그가 꺼져 있으면 위 화면이 전부 upstream 그대로 나온다.
- [ ] 커뮤니티 나가기가 UI에서 동작한다. upstream의 탈퇴 요청 이벤트가 있으면 그대로 쓰고, UI가 없으면 커뮤니티 메뉴에 추가한다. 나가면 로컬 목록에서 제거되고 다른 커뮤니티 또는 두 카드 화면으로 돌아간다.
- [ ] Playwright smoke: 플래그 켜짐 시 키 관련 문구 부재, 나가기 동작. 플래그 꺼짐 시 기존 카드 존재.
